# گلیا کنکور — لایتنر هوشمند

این پروژه، فایل HTML مرجع ارائه‌شده را به‌عنوان هستهٔ UI و منطق مرور داخل یک پوستهٔ Flutter/Android اجرا می‌کند. بنابراین کارت‌ها، ترتیب داده‌ها، طراحی، انیمیشن‌ها، فیلترها، وضعیت‌های «بلدم/نمی‌دانم»، آمار، تنظیمات و منطق لایتنر مستقیماً از همان HTML می‌آیند.

## معماری

- Flutter + WebView
- فایل `assets/leitner.html` شامل محتوای کامل HTML مرجع است.
- پشتیبانی APK برای `armeabi-v7a`، `arm64-v8a` و `x86_64`
- GitHub Actions برای build خودکار و Release با tag

## ترتیب و منطق کارت‌ها

HTML اصلی ابتدا `fullDeck` را از انگلیسی، افعال بی‌قاعده، فارسی و عربی می‌سازد. لیست‌های آموزشی از همان داده‌ها render می‌شوند و در حالت مرور، همان الگوریتم اصلی وضعیت یادگیری و shuffle را اعمال می‌کند. بنابراین ترتیب لیست‌ها و رفتار مرور از کد اصلی تغییر داده نشده است.

## لوگو

لوگوی انتخاب‌شده توسط مالک برنامه در نسخه آمادهٔ محلی پروژه در `assets/logo.png` قرار دارد و داخل HTML نیز به‌عنوان لوگوی Splash و نوار بالایی استفاده می‌شود.

## نسخه و Update

نسخه فعلی `1.0.0+1` است. برای نسخه بعدی، version را افزایش دهید و tag جدید مانند `v1.0.1` بسازید.

برای نصب نسخه جدید روی نسخه قبلی باید تمام Releaseها با همان کلید امضای Android ساخته شوند. کلید امضا را داخل Git قرار ندهید و برای انتشار واقعی از GitHub Actions Secrets استفاده کنید.

## Play Protect

هیچ پروژه‌ای نمی‌تواند نتیجه Play Protect را ۱۰۰٪ تضمین کند. این پروژه از Flutter و WebView رسمی استفاده می‌کند و cleartext HTTP را غیرفعال می‌کند. برای انتشار عمومی، APK باید با یک کلید Release ثابت و متعلق به مالک برنامه امضا شود.
